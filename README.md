# CONÓCETE
Recorrido interactivo de autoconocimiento emocional para estudiantes de grado décimo (HTML5 + CSS3 + JavaScript).

## Esta carpeta es la PÚBLICA
Es lo único que se sube a GitHub Pages. Llega hasta el resultado y los recursos de ayuda. No contiene datos ni panel de análisis.

```
index.html · css/styles.css · js/ (mascot, data, logic, stats, app) · docs/
```
El panel de sistematización está aparte, en `PRIVADO_solo_para_mi` (no se sube).

## Publicar gratis en GitHub Pages
1. En github.com: **New repository** → nombre `conocete`, público.
2. **uploading an existing file** → arrastra el CONTENIDO de esta carpeta (incluido `.nojekyll`) → **Commit changes**.
3. **Settings → Pages** → *Deploy from a branch* → rama `main`, carpeta `/ (root)` → **Save**.
4. En 1–3 minutos: `https://TU-USUARIO.github.io/conocete/`.
